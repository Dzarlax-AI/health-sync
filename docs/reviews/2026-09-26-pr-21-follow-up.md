# PR #21 review follow-up

## Changes

- Preserve locked/unavailable-credential outcomes after channel work, including a lock after an upload, instead of reporting state persistence failure.
- Retry persisted background work on launch and activation even when sync-on-launch is disabled. Gate execution on background-sync permission and protected-data availability; coalesce concurrent recovery triggers.
- Persist the original daily-resync calendar interval across process restarts and delayed unlocks. Merge pending ranges and prevent unrelated receipts or late completions from clearing newer retry intent. Migrate the prior boolean marker without reading credentials.
- Transfer the HealthKit completion callback through a lock-protected, exactly-once bridge; use explicit Sendable and MainActor annotations at the queue boundary.
- Keep server facts when optional AI objects or slot metadata are malformed. Invalid or missing per-slot approval fails closed instead of falling back to aggregate AI readiness.
- Record delivery success only on state changes or recovery from failure; repeated no-op setup no longer crowds out diagnostic events.
- Decouple energy loading from the arrival of insights. While visible and active, observe account, language, and day changes without duplicate initial requests.

## Validation

- Reproduction: the new locked-outcome assertion and both malformed-AI/slot tests failed on the previous implementation. All 38 tests emitted their results; xcodebuild hung during cleanup and was terminated after preserving the log.
- Final Simulator run: **115 passed, 0 failed, 0 skipped** on iPhone 17 Pro / iOS 26.5: 113 unit tests and two UI tests for domain navigation/energy history and both themes.
- The actual observer, protocol, and completion bridge source passed a standalone typecheck with `-swift-version 6 -strict-concurrency=complete -default-isolation MainActor`.
- Existing project language settings remain Swift 5 mode; this is not a project-wide Swift 6 migration. Existing actor-isolation warnings in older test files remain outside this patch.
