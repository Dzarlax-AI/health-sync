Setup & support

Connect your server

Ask your Health Dashboard server administrator for the server URL and an API key. In Settings, expand Connection details, enter them and tap Test connection. The app does not create server accounts or provide a hosted server.

Choose Health access

Choose the metric categories and workout options you want to upload, then run Sync now and review the Health access request. You can change access later in iOS Settings. Missing permission or missing Health records can leave charts empty.

Check delivery

Recent activity & re-sync shows upload results and retry actions. Server acceptance confirms delivery, not completion of server processing. iOS controls background scheduling, so the selected interval is not a guaranteed upload frequency.

Get help safely

For server access, account details or deletion requests, contact your server administrator. For app setup and troubleshooting, open the project documentation below. Do not include API keys, health records or private server details in public reports.

Project documentation

Contact app support

Email the developer at dzarlax@gmail.com. Include your app and iOS versions and the steps needed to reproduce the issue. For server account access, stored health records or deletion, contact the operator of your configured server. Never send API keys or health records in a public report.

Настройка и поддержка

Подключение сервера

Получите адрес сервера и API-ключ у администратора Health Dashboard. В настройках раскройте раздел «Детали подключения», введите их и нажмите «Проверить подключение». Приложение не создаёт аккаунты на сервере и не предоставляет сервер.

Выбор доступа к данным здоровья

Выберите категории метрик и параметры тренировок для отправки, затем нажмите «Синхронизировать» и проверьте запрос доступа к данным здоровья. Позже доступ можно изменить в настройках iOS. Если разрешение не выдано или записей нет, графики могут быть пустыми.

Проверка отправки

В разделе недавних отправок и повторной синхронизации доступны результаты и повторные попытки. Принятие данных сервером подтверждает доставку, но не завершение их обработки. Расписание фоновой работы определяет iOS, поэтому выбранный интервал не гарантирует частоту отправки.

Обращение за помощью

По вопросам доступа, аккаунта и удаления данных обращайтесь к администратору своего сервера. Инструкции по настройке и устранению неполадок доступны в документации проекта ниже. Не публикуйте API-ключи, данные здоровья и приватные сведения о сервере в открытых обращениях.

Podešavanje i podrška

Povezivanje sa serverom

Zatražite adresu servera i API ključ od administratora Health Dashboard servera. U podešavanjima otvorite detalje veze, unesite ih i proverite vezu. Aplikacija ne kreira naloge na serveru niti obezbeđuje server.

Izbor pristupa zdravstvenim podacima

Izaberite kategorije metrika i opcije treninga za slanje, zatim pokrenite sinhronizaciju i pregledajte zahtev za pristup zdravstvenim podacima. Pristup kasnije možete promeniti u podešavanjima iOS-a. Bez dozvole ili odgovarajućih zapisa grafikoni mogu ostati prazni.

Provera slanja

Odeljak za nedavnu aktivnost i ponovnu sinhronizaciju prikazuje rezultate slanja i ponovne pokušaje. Prihvatanje na serveru potvrđuje isporuku, ali ne i završetak obrade. iOS određuje raspored rada u pozadini, pa izabrani interval ne garantuje učestalost slanja.

Bezbedno traženje pomoći

Za pristup serveru, nalog ili brisanje podataka obratite se administratoru svog servera. Za podešavanje aplikacije i rešavanje problema otvorite dokumentaciju projekta ispod. Ne objavljujte API ključeve, zdravstvene zapise ili privatne podatke o serveru u javnim prijavama.
